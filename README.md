### 🍽️ Food Ordering App

This is my first frontend project, created after completing my frontend development course.  
It’s a static, responsive food ordering template built using **HTML** and **CSS**, designed for both desktop and mobile views.

🔗 **Live Preview:** [food-ordering-apps.netlify.app](https://food-ordering-apps.netlify.app)

---

### 🚀 Features

- 🧾 Static food ordering layout
- 📱 Fully responsive design for mobile and desktop
- 🎨 Clean and modern UI using HTML & CSS
- 🧠 Beginner-friendly structure for customization

---

### 🛠️ Tech Stack

| Layer     | Technology |
|-----------|------------|
| Markup    | HTML       |
| Styling   | CSS        |
| Deployment| Netlify    |

---

### 📦 Installation

```bash
# Clone the repository
git clone https://github.com/ram-bhagat-thakur/Food-Ordering-Apps.git
cd Food-Ordering-Apps

# Open index.html in your browser
No build tools or backend setup required. Just open the HTML file and you're good to go.
```

### 📁 Project Structure

